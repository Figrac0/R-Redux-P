# Redux Basics — Functional & Class Components with Redux Toolkit

This project demonstrates the **fundamental concepts of Redux** integration in **React** using both **functional** and **class-based components**.

It provides a minimal, clear example of how to:
- Use **React Redux hooks** (`useSelector`, `useDispatch`) in functional components.  
- Connect **class components** via `connect()` and `mapStateToProps` / `mapDispatchToProps`.  
- Organize code using **Redux Toolkit** (`createSlice`, `configureStore`).  
- Manage multiple slices of state (e.g., `counter`, `auth`).  
- Dispatch actions and update UI reactively.

### Purpose
To serve as a **base reference** or **learning template** for understanding:
- Core Redux data flow
- Store configuration via Redux Toolkit
- Integration of multiple slices
- Transition from legacy Redux (`connect`) to modern React hooks

Perfect for developers beginning with **Redux + React** or revisiting **Toolkit fundamentals**.
